# THE FOREST

PC / PCVR-first survival horror game. The HTML build is used for development and browser testing.

## Current GitHub assets

- `tree-low-poly-lowpoly.zip` — supplied Tree 1 and 2 FBX and texture.
- `campfire.glb` — supplied campfire model.
- `rock.zip` — supplied rock model pack.

## Android test build

See [ANDROID_BUILD.md](ANDROID_BUILD.md) for how to merge the current repair upload pack and build the Android debug APK with GitHub Actions.

Note: APK files install on Android devices, not iPads. iPad browser testing uses Safari; a native iPad app requires a separate iOS build.
