# THE FOREST

PC / PCVR-first psychological survival horror game. HTML development and PC testing build uses the bundled Three.js r160 runtime, the supplied tree/rock/campfire assets, and the player/monster models.

## Game builds

- PC: download `THE_FOREST_PC_Controls_Models_Build.zip` from the current ChatGPT build response, extract it and run `START_THE_FOREST.bat`.
- Android test APK: follow [ANDROID_BUILD.md](ANDROID_BUILD.md). The Actions workflow needs the current game HTML, Rootbound Sentinel FBX and three player asset chunks uploaded to the repository.
- APK is Android-only; iPad testing uses Safari until a separate iOS build is made.

Current repository assets: `three-runtime/`, `tree-low-poly-lowpoly.zip`, `campfire.glb`, and `rock.zip`.
